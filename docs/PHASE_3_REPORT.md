# Phase 3 checkpoint: Listen & Find

Implemented the first playable listening loop with unified touch/mouse input, local Edge TTS prompts, randomized picture choices, gentle wrong-answer feedback, unlimited retry, replay, hint, pause/resume, explicit Next/Finish, stars and restart. Child-facing UI is English throughout. Session notes show unhinted first-choice correctness, successful explicit replays and hint requests; these are observations, not vocabulary mastery. Duration is elapsed wall time, including pauses.

Curriculum provenance: Cambridge Power Up 0, Unit 3 Food shopping, Vocabulary 1, printed page 28, visually verified in Phase 2. Five words: apple, banana, grapes, orange, watermelon. Independent sampler adds pear and uses woodland scenery; it is explicitly marked as demo content. Only original SVG illustrations and generated TTS MP3s are committed. No textbook collection, credentials or original recordings are included. The 500-word goal remains a later content/learning goal.

Architecture: shared Phase 1 contracts remain unchanged. Core/learning remain framework-independent. Tap emits selections, RuleEngine evaluates, RewardManager deduplicates grants, runtime composes managers and publishes through the bridge. Scene code contains no mechanic dependency, and React receives no Phaser references. Supported runtime options are validated explicitly. Restart resets session/rewards/counters; disposal invalidates async work and destroys listeners, audio and viewport.

Audio: Microsoft Edge TTS en-GB-SoniaNeural at -10%, generated by scripts/generate-prompts.py. Playback uses Web Audio; environments without AudioContext use HTML Audio with original same-origin URLs because Windows WebKit cannot play the generated blob URLs. Corrupt playback locks selection, surfaces Listen recovery and reloads the asset on retry. No microphone or ASR integration is included.

## Human acceptance still required

Run pnpm dev and open the printed local URL. For an iPad on the same network, run pnpm --filter @english/web dev --host 0.0.0.0 and open the computer's LAN address with the printed port.

1. On physical iPad Safari, start from a tap and check audible prompts, picture hit areas, portrait/landscape layout, pause/resume, background/foreground, replay and a complete five-round session.
2. With a beginner child, demonstrate listening and tapping once. Observe whether they can continue without reading English instructions; record any adult help needed.
3. Let the child choose without hints first. Note first choices, replay/hint usage and whether choices seem based on the spoken word. Separate prompted/cued responses from independent responses.
4. Observe reaction to a wrong choice and whether retry feels clear. Offer another session without pressure; record whether the child voluntarily continues and where interest fades.
5. Share device/browser, approximate age and prior exposure, confusing moments, adult help, session notes and willingness to replay. Do not infer vocabulary mastery from stars or a single session.

Limitations: physical iPad Safari, child comprehension/engagement and device performance are unverified. Automated WebKit is emulation. Introductory instructions are currently English text and icons; generated welcome/feedback audio assets are not yet wired into gameplay. Whether beginners need an adult demonstration or spoken onboarding must be assessed during playtesting. Phaser produces a large-chunk build warning. No durable progress, backend, 500-word library, Voice Match, Slice or pronunciation scoring is delivered at this milestone. Phase 4+ remains outside scope pending user review.
