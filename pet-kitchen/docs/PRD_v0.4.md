## 2. 双货币经济系统（定稿）

| 货币 | 唯一产出 | 消耗 | 驱动 |
|------|---------|------|------|
| **食物** | 完成打卡任务、连续打卡奖励 | 喂养宠物 | 饱食度 → 体型 + 经验 → 6 阶进化 |
| **积分** | **仅学科闯关**（Q19 无保底） | 商店装饰、现实奖品兑换 | 家园个性化、现实激励 |

> **风险提示（未解除）**：不闯关 = 零积分 = 商店与现实奖品完全失效。对"抗拒做题"的孩子等于失去一半激励。
> 建议至少保留"家长在成长报告页手动奖励积分"作为兜底出口（D3，非阻塞）。

## 3. 饱食度与体型模型（定稿）

### 3.1 食物发放规则

| 场景 | 食物 |
|------|------|
| 完成单个打卡任务 | +1（家长可设 1~3） |
| 当日全部完成 | **无额外奖励** |
| 连续打卡第 7 天 | +1（当天一次性） |
| 连续打卡第 30 天 | +5（当天一次性） |
| 断签 | 连续天数清零，重新累计 |

### 3.2 饱食度参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 饱食度区间 | 0 ~ 120 | UI 进度条按 100 为满，100~120 显示为琥珀色"撑到了" |
| 每份食物 | +20 | — |
| 每日自然衰减 | **60** | 每日 04:00 结算 |
| 日投喂上限 | 6 次 | 可一次投喂多份（如一次投 3 份） |
| 维持成本 | **3 份/天** | 3 份 = 净变化 0 |
| 顶格定义 | 当日结算饱食度 ≥ 100 | 触发"连续 7 天"计数 |

### 3.3 为什么衰减从 100 下调到 60（重要）

若每日衰减 100，则 **5 份/天 是"活命线"而非"顶格线"**——孩子为了不让宠物饿瘦，必须天天喂到 100，结果必然触发"连续 7 天顶格吃 → 肥胖"。
**孩子将只有"饿瘦"和"变胖"两种结局，不存在健康态**，这违背"不惩罚孩子"的设计原则。

下调到 60 后：

| 每日投喂 | 净变化 | 结果 |
|---------|--------|------|
| 0 份 | −60 | 饿了（连续 3 天 → 消瘦） |
| 1~2 份 | −40 / −20 | 缓慢变瘦 |
| **3 份** | **±0** | **健康维持** |
| 4 份 | +20 | 有盈余，正常 |
| 5 份 | +40 | 可达顶格 100（连续 7 天 → 肥胖） |
| 6 份 | +60 | **当日肥胖** |

### 3.4 体型状态机

```
                    每日 04:00 结算
                          ↓
    ┌────────────────────────────────────────┐
    │                                        │
  消瘦  ←── 连续 3 天投喂 0 份 ──  正常  ── 单日投喂第 6 份 ──→  肥胖
    │                                ↑              │
    └──── 任意投喂 ≥1 份 ─────────────┘              │
                                                    │
              当日投喂 ≤4 份 且 未顶格 → 次日恢复 ────┘
                    连续 7 天当日结算饱食度 ≥100 → 肥胖
```

| 体型 | 触发 | 恢复 | 影响 |
|------|------|------|------|
| **正常** | 默认 | — | — |
| **消瘦** | 连续 3 天投喂份数 = 0 | 任意一天投喂 ≥1 份，当日结算恢复 | 仅视觉 + 成长报告文案 |
| **肥胖** | ① 单日投喂第 6 份<br>② 连续 7 天当日结算饱食度 ≥100 | 当日投喂 ≤4 份且未顶格，次日结算恢复 | 仅视觉 + 成长报告文案 |

**硬性约束**：三种体型**均不做属性惩罚**（不扣经验、不掉阶、不影响闯关）。

### 3.5 收支平衡表（默认单任务 = 1 份）

| 家长设置任务数 | 每日产出 | 维持需 3 份 | 结论 |
|--------------|---------|-----------|------|
| 2 个 | 2 份 | 不足 | 建议家长把单任务食物值调到 2 |
| 3 个 | 3 份 | 刚好 | 健康，无盈余 |
| 5 个 | 5 份 | 盈余 2 份 | 孩子需学会"吃饱就停"，否则易触发肥胖 |
| 6 个以上 | 6+ 份 | 盈余多 | 食物可储蓄，鼓励攒着 |

> 家长端（P16）必须显示实时提示：`当前每日产出 X 份 · 宠物维持需 3 份/天`，产出 < 3 时标红提醒。

## 5. 模块需求

### 5.1 Day 0：领养与孵化

1. 3 颗山海经蛋横排展示（MVP 先出 1 种，另 2 种置灰"敬请期待"）
2. 可**自由切换预览**（Q26），未点确认前均可更改
3. 点击**"确认领养"** → 二次弹窗"确定选它吗？选好就不能换啦" → 锁定
4. 破壳动画 → 揭晓宠物 → 取名（支持后改，6 字内，敏感词过滤）
5. 引导完成第一个打卡任务
6. 进入家园稳定态

### 5.2 打卡任务

- 类型：拍照类（自动通过）、录音类（自动通过）、主观类（家长确认）
- 单任务 +1 食物（可配 1~3），无全勤奖
- 连击：7 天 +1、30 天 +5；断签清零
- 佐证：照片 / 录音加密存储，默认 30 天自动清理

### 5.3 宠物养成

- **6 个进化阶段**，经验累积驱动（每投喂 1 份食物 +经验，D5 待定具体值）
- **3 种体型**：瘦 / 正常 / 胖（规则见 3.4）
- **三科属性**：语文力 / 数学力 / 英语力，由闯关表现提升
  - 作用（Q24）：决定**关卡解锁门槛** + 闯关内**血量 / 提示次数**

### 5.4 学科闯关

- **数学优先**（学而思一年级速算体系，10 个技巧点：凑十法 / 破十法 / 平十法等，需教研复核）
- 语文、英语按深圳教材（**需提供教材目录，否则不能开工**）
- 难度固定按年级（Q11）
- **PK 对象 = 系统 Boss（PvE）**，无真人对战（Q23）
- 错题 → 错题集 → 举一反三变式题 → 注入下次关卡（间隔 1/3/7/15 天）

### 5.5 商店与现实奖品

- 装饰：积分购买 → 家园拖动摆放
- 现实奖品：家长设置所需**积分**（Q22）→ 孩子兑换 → **家长审批** → 线下兑现 → 标记已兑现

### 5.6 家长端（最小集）

| 模块 | 功能 |
|------|------|
| 任务管理 | 任务增删改、食物值设置（1~3）、打卡确认、手动调整食物、收支提示 |
| 现实奖品管理 | 奖品设置、**兑换审批**、标记兑现 |
| 成长报告 | 周报：完成率、连续天数、宠物阶段与体型、闯关正确率、错题攻克数、积分收支 |

## 6. 数据模型

| 实体 | 关键字段 |
|------|---------|
| 宠物 | 种类、昵称、阶段(1-6)、经验、饱食度(0-120)、体型、当日已投喂份数、连续未喂天数、连续顶格天数、三科属性、确认锁定标志 |
| 任务模板 | 名称、图标、食物值(1-3，默认1)、周期、类型(拍照/录音/主观) |
| 每日任务 | 日期、模板、状态、佐证URL、确认人 |
| 食物流水 | 变动值、来源（打卡/连击/家长调整/喂养消耗）、余额、时间 |
| 积分流水 | 变动值、来源（闯关/消费/兑换）、余额、时间 |
| 错题 | 题目、知识点、错误次数、下次重练日期、掌握状态 |
| 奖品 | 名称、所需积分、状态（可兑换/待审批/已兑现） |
| 每日快照 | 日期、结算后饱食度、当日投喂份数、是否顶格、体型 |

## 7. MVP 与分期

**P0（可上线）**：网页骨架 + 顶部 Tab｜领养孵化（先 1 种宠物）｜打卡三类核验｜食物与喂养｜6 阶进化 + 3 体型｜数学闯关（10 技巧点）｜错题举一反三（数学）｜商店基础｜家长端最小集

**P1**：语文闯关｜英语闯关｜现实奖品审批流｜连击与断签｜家园自由摆放

**P2**：另 2 种宠物补齐｜成就/稀有装饰｜成长报告可视化升级

**Non-goals**：无社交、无 PvP、无宠物死亡惩罚、无真实货币充值、无广告、无多孩、无自适应难度

## 8. 合规与风险

| 风险 | 应对 |
|------|------|
| 儿童个人信息 | 昵称非真名、不采集人脸、照片/录音加密存储并设自动清理（建议 30 天） |
| 防沉迷 | 单次闯关限时 15 分钟，家长端可设每日上限 |
| 教材版权 | 题库原创编写或改编，不复制教材原文与插图 |
| **教材版本未知（阻塞）** | 我无法确认 2026 秋深圳一年级实际教材版本（语文推测统编版、英语推测沪教牛津深圳版）。**需家长提供教材封面或目录**，否则语文/英语题库不能开工 |
