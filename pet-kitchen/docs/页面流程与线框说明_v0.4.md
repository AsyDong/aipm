## 阅读约定

- 每个页面固定五段：**线框 / 元素与规则 / 状态 / 交互与跳转 / 异常与边界**
- 单位：份（食物）、分（积分）、点（饱食度 / 经验）
- 金额与数值全部引用 PRD v0.4 定稿值
- 所有面向孩子的文案控制在 **10 字以内**，并支持点击朗读（1~2 年级识字量有限）

## 1. 全局框架

### 1.1 顶部 Tab（常驻，4 个页面共有）

```
┌───────────────────────────────────────┐
│   家园    闯关    商店    我的         │
│   ●       ○       ○       ○          │   ← 当前 Tab 高亮 + 图标
└───────────────────────────────────────┘
```

| 项 | 规则 |
|----|------|
| 位置 | 固定顶部，不随页面滚动 |
| 高度 | 56px（含安全区） |
| 点击热区 | ≥ 48 × 48px（低龄儿童手指精度） |
| 未解锁 Tab | 不置灰 Tab 本身，进入后显示引导（避免孩子困惑） |

### 1.2 通用组件

| 组件 | 规格与规则 |
|------|-----------|
| **币种胶囊** | 右上常驻，显示 `食物 x N` / `积分 x N`。数值变化时跳动动画 +0.3s。积分不足时数字变灰 |
| **宠物卡** | 主视觉 + 昵称 + 阶段（~~体型角标~~ 已于 2026-09-17 移除） |
| **主按钮** | 高度 52px，圆角 16px，**一次只出现一个主操作**（低龄认知） |
| **二次确认弹窗** | 不可逆操作必弹（确认领养、兑换奖品、清空布置）。文案用孩子口吻 |
| **Toast** | 顶部下滑，2.5s 自动消失，字数 ≤ 12 字 |
| **空状态** | 插画 + 一句引导 + 一个主按钮 |
| **加载态** | 宠物蛋摇晃动画（复用主视觉，成本低） |

### 1.3 全局规则

| 规则 | 定义 |
|------|------|
| 每日结算时刻 | **04:00**。执行：饱食度 −60、判定连击、重置当日投喂份数（~~判定体型~~ 已于 2026-09-17 移除） |
| 一"天"的定义 | 04:00 ~ 次日 04:00（不是自然日 0 点，避免孩子熬夜赶任务） |
| 断签 | 某日无任何任务完成 → 连续天数清零 |
| 家长模式入口 | 「我的」页底部，4 位数字密码，默认 `1234`，首次进入强制修改 |
| 家长模式退出 | 自动锁定：离开家长页 5 分钟后需重新输入密码 |

| 元素 | 规则 |
|------|------|
| 3 颗蛋 | 三颗全部开放（朏朏 / 当康 / 天狗，均为《山海经》正向祥瑞） |

**交互**：选蛋 → 主按钮激活 → 点击 → 二次弹窗"确定选它吗？选好就不能换啦"（两个按钮：再想想 / 确定）→ P02
**异常**：
- 刷新页面 → 未确认状态不保存，重新选择
- 已确认过 → 直接跳过到 P04

- 默认：有未完成任务

- 空状态（家长未配置任务）：显示"还没有任务哦，请爸爸妈妈先添加"

**交互**
- 点击任务 → P06 提交页
- 点击喂食 → P05
- 点击宠物 → 台词气泡 + 轻微跳动

**异常与边界**
- 食物 = 0 → 喂食按钮置灰，Toast"先去完成任务吧"
- 饱食度 = 100（当前上限，喂满 5 份即达）→ 喂食按钮置灰 + "宝宝吃好啦，明天再来"
- 当日已投喂 5 次（当日上限）→ 喂食按钮置灰 + "今天喂满啦，明天再来吧～"
  （原为「已投喂 6 次 + 此时宠物已判肥胖」，体型机制已于 2026-09-17 移除）

```

├───────────────────────────────────────┤
│            喂 小 火 火                  │

│   ┌────┐ ┌────┐ ┌────┐               │
│   │ 1份 │ │ 3份 │ │ 加满│               │

│                                       │
│   ⚠ 再喂 1 份就顶格啦                   │
└───────────────────────────────────────┘
```

| 元素 | 规则 |
|------|------|
| 快捷投喂 | **1 份 / 3 份 / 加满** 三个按钮（避免低龄孩子理解数字输入） |
| "加满" | 投喂到饱食度 100 所需份数，`ceil((100 - 当前)/20)`，最多 5 份 |
| 进度预览 | 点击按钮后面板上预览"60 → 80"，不即时提交 |
| 已喂次数 | 显示 `今日已喂 N / 5` |
| 警告文案 | 当日已喂 4 次时显示"⚠ 再喂 1 份就顶格啦"；已喂满 5 次时显示"今天喂满啦，明天再来吧～"（不再出现体型相关提示） |
| 经验提示 | 投喂后浮出 `+20 饱食度  +X 经验` |

**交互**：选份数 → 面板预览 → 点击"确定投喂"（面板内主按钮）→ 食物扣减、饱食度上升、宠物吃食动画 → 关闭抽屉
**异常**：
- 食物不足 → 对应按钮置灰
- 已达 5 次（当日上限）→ 全部按钮置灰 + "今天喂满啦，明天再来吧～"
- ~~连续 6 天顶格 → 额外提示"已经连续 6 天吃得好饱，明天别喂满啦"~~ **【已作废】**（随体型机制一并移除）

```

│         ╰─────────────────╯           │
│                                       │
│      ┌────────┐  ┌────────┐          │

│   │      完 成 啦 ！              │    │
│   └─────────────────────────────┘    │
└───────────────────────────────────────┘
```

| 元素 | 规则 |
|------|------|
| 提交方式 | 由任务类型决定：拍照类只显示拍照 / 录音类只显示录音 / 主观类显示拍照 + 录音二选一 |
| 拍照 | 调用 `input[type=file][capture]`，压缩至 ≤ 800KB |
| 录音 | 最长 60s，可试听重录 |
| 完成按钮 | 提交后主按钮变"等待爸爸妈妈看"（仅主观类） |

**状态**
- 拍照/录音类：提交 → **自动通过** → 食物 +1 → 成功动画 → 返回 P04
- 主观类：提交 → 状态"待确认" → 任务卡显示⏳ → 家长在 P16 确认后食物到账 + Toast 通知

**异常**
- 无相机/麦克风权限 → 引导页"请允许使用相机"（图文步骤）
- 上传失败 → Toast"没传上去，再试一次"+ 保留本地草稿
- 重复提交同日任务 → 已完成的不可再点

| 答错 | 扣 1 血 → 立即显示正确解法（教学优先于惩罚）→ 进入错题集 |
| 答对 | Boss 扣 1 血 → 下一题 |
| 提示 | 次数 = `floor(属性 / 10) + 1`，用完后按钮置灰 |
| 限时 | 单关 15 分钟（防沉迷），剩余 2 分钟时提示 |

**状态**：进行中 / 血量归零（失败）/ 全部答完（胜利）
**异常**：

- 退出 → 弹窗"现在退出，这关要重来哦"；确认后进度不保存
