**已解耦的一处约束**：原先「同步」和「远端出题」共用 `VITE_API_BASE_URL`，留空就两个全关。
现在同步有独立的 `VITE_SYNC_URL`，而 `VITE_PREFER_REMOTE=0` 可以强制本地出题 ——
**上线推荐「本地出题 + 同域同步」**：出题零延迟零成本，同步照常走服务器。

## 二、生产环境变量（`.env.production`）

```
# 出题走本地：题库是程序化生成的，远端绕一圈没有收益，还多一个失败面
VITE_API_BASE_URL=
VITE_PREFER_REMOTE=0

# 同步走同域（nginx 反代到 127.0.0.1:8787）；令牌必须与服务器 SYNC_TOKEN 一致
VITE_SYNC_URL=https://petkitchen.com
VITE_SYNC_TOKEN=<与服务端 SYNC_TOKEN 相同的值>
```

> ⚠️ `VITE_` 开头的变量会被打进前端 bundle，等同半公开凭证 —— 它只够写 `/api/sync`，
> 能读全量数据的 `/api/report` 刻意不发给前端。生产必须做两件事：nginx 同域反代 + 给 `/api/sync` 限流（配置里已有）。

```bash
# 3) 服务器：DNS 解析 → 证书（DNS 生效后再执行）
#    A 记录：petkitchen.com / www.petkitchen.com → 124.222.148.45

# 4) 收口：8787 只允许本机（iptables / 安全组）
#    云厂商安全组里删掉 8787 的公网放行，或只放行 127.0.0.1
```

## 四、ICP 备案（境内服务器必须，OPS 前置）

**为什么必须做**：服务器在境内（腾讯云），未备案的域名用 80/443 对外提供网站服务会被拦截。
备案通过前，`https://petkitchen.com` 打不开 —— 这一步是**时间上的关键路径**（通常 1~20 个工作日），建议**尽早提交**。

**需要你提供的信息**（我这边无法代办）：

| 项 | 说明 |
|---|---|
| 主体类型 | 个人 / 企业（个人可用，但部分省份要求网站名与主体相关） |
| 主体证件 | 身份证 / 营业执照 + 法人身份证 |
| 负责人手机号 + 邮箱 | 用于核验与接收通知 |
| 应急联系电话 | 备案要求填写 |
| 域名证书 | 域名注册商控制台可下载 |
| 服务器实例 | 备案服务号（腾讯云控制台 → 备案 → 用本台轻量实例申请） |
| 网站名称 | 建议「小小闯关家」这类中性名，不要含「教育」等需前置审批的词 |
| 网站服务内容 | 选「其他」，描述写「家庭教育辅助工具」 |

> 提示：个人备案的通过率取决于省份。若走企业主体，通过更快、后期也不用改。
> 备案信息里的网站内容描述**不要**出现「在线教育」「培训」等字眼 —— 可能被要求补前置审批。
